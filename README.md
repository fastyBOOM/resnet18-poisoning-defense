# Модификация двухстадийного метода фильтрации отравленных данных

Репозиторий содержит материалы практики по исследованию устойчивости сверточных нейронных сетей к бэкдор-атакам (BadNets).

**Научный руководитель:** к.ф.-м.н., доцент Балахчи Анна Георгиевна.

## Описание проекта
В работе реализована бэкдор-атака BadNets на наборе данных CIFAR-10 для модели ResNet-18 (успешность атаки ASR = 95.47%). 
Воспроизведен базовый метод защиты Activation Clustering (Chen et al.) и предложена модификация — алгоритм двухстадийной гибридной фильтрации латентного пространства признаков на основе итерационного отсечения периферийных аномалий по критерию Z-score.

## Структура репозитория
* `Andreev_DA_Practice_2026_v2.ipynb` — Jupyter-ноутбук с полным циклом экспериментов (атака, базовая защита, модифицированный метод).
* `requirements.txt` — список необходимых библиотек для развертывания окружения.
